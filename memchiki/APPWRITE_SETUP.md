# Настройка Appwrite

Приложение больше не использует `localStorage`: профили и сессии ведёт Appwrite Auth, категории/мемы/лайки — Appwrite Database, картинки — Appwrite Storage.

1. В проекте Appwrite создай Web platform для адреса приложения (для Vite локально также добавь `localhost`).
2. Создай базу данных **TablesDB**. ID базы созданной в консоли уже известен: `6af976f90011b6df66b8`.
3. Создай таблицы со следующими колонками. Используй фактические ID таблиц из заголовка консоли в `.env.local` — Appwrite автоматически генерирует ID.

| Таблица | Колонки |
| --- | --- | --- |
| Категории | `name` — Text, обязательно |
| Мемы | `payload` — Text, обязательно |
| Лайки | `payload` — Text, обязательно |

4. Для каждой таблицы выдай на уровне таблицы: **Create — Users**, **Read — Any**. Права Update/Delete строки получают при создании: только создатель и (необязательно) команда администраторов.
5. Создай bucket с ID `meme-images`, включи file security. Выдай ему **Create — Users**, **Read — Any**. Максимальный размер файла — 2 MB; разрешённые расширения: JPG, PNG, WebP, GIF.
6. Скопируй `.env.example` в `.env.local`. Вставь endpoint из **Overview** проекта и реальные ID, если выбрал другие. Файл `.env.local` не коммить.
7. Если нужны общие права модерации, создай Team в Appwrite, добавь его ID как `VITE_APPWRITE_ADMIN_TEAM_ID`, а модераторов — в эту команду. Не задавай админ-права по имени пользователя.

После этого запусти `npm run dev`, зарегистрируй первый аккаунт через кнопку профиля и проверь создание категории, мема с картинкой и лайка.
